# Этап 2 курсового проекта

Тема: «Проектирование и разработка базы данных "Сеть автосалонов"».

Разработать и заполнить таблицы базы данных с использованием выбранной СУБД. Создать программное приложение для работы с БД и отладить его.

Общие требования: не менее четырех связанных таблиц, вычисляемые столбцы, не менее десяти записей в каждой таблице. Реализовать добавление, удаление и поиск информации.

Для сдачи этапа необходимо предоставить все файлы программного проекта. Срок по скриншоту личного кабинета: 8 января 2027 года.
