# Этап 2. Разработка приложения для БД «Сеть автосалонов»

## Результат
Подготовлен архив «Курсовой_проект_Сеть_автосалонов_Этап_2.zip» с Python-приложением, рабочей базой SQLite, SQL-скриптами, проверками и снимками экрана.

Состав архива:
- `Программа/autosalon.py`: настольное приложение Tkinter.
- `Программа/autosalon.db`: демонстрационная база SQLite.
- `Программа/autosalon_schema.sql`: схема восьми таблиц.
- `Программа/autosalon_data.sql`: первоначальное заполнение.
- `Программа/proverka_raboty.py`: автоматические проверки.
- `Программа/ekran_avtomobili.png`, `Программа/ekran_otchety.png`: снимки экрана.
- `README.txt`: инструкция запуска.

## Проверка требований
| Таблица | Число записей |
|---|---:|
| salons | 10 |
| brands | 10 |
| models | 12 |
| vehicles | 24 |
| customers | 12 |
| employees | 12 |
| sales | 12 |
| payments | 16 |

Реализованы CRUD, поиск и фильтрация, учет продаж и платежей, отчеты по наличию, выручке, менеджерам и задолженности. Вычисляемые столбцы: `planned_margin` и `final_amount`.

Автоматические проверки прошли: ключи и связи, вычисляемые поля, CRUD, отчеты, запрет повторной продажи, запрет переплаты.

Запуск: `python autosalon.py`. Для проверки: `python proverka_raboty.py`. Нужен Python 3.10+ с Tkinter.
