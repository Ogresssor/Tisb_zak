# Этап 2. Программа «Сеть автосалонов»

Второй этап курсового проекта по базам данных. Приложение написано на Python с Tkinter, база данных SQLite.

## Состав сдаваемого архива
- `Программа/autosalon.py`: приложение с обычными формами для просмотра и редактирования.
- `Программа/autosalon.db`: база данных с примерами.
- `Программа/autosalon_schema.sql`: структура таблиц.
- `Программа/autosalon_data.sql`: заполнение таблиц.
- `Программа/proverka_raboty.py`: проверка основных операций.
- `Программа/ekran_avtomobili.png`, `Программа/ekran_otchety.png`: снимки экрана.
- `README.txt`: простая инструкция.

Исправленное издание архива: `Курсовой_проект_Сеть_автосалонов_Этап_2_исправлено.zip`. Архив предоставлен в чате, бинарные файлы в GitHub пока не загружены.

## Функции
Добавление, изменение, удаление, поиск записей в восьми таблицах. Отчеты о наличии автомобилей, продажах, менеджерах и оплате. Автоматический расчет плановой маржи и цены со скидкой.

## Проверка

|---|---:|

Проверка целостности внешних ключей: ошибок нет. Проверены функции работы с записями, ограничения на продажу и платежи. Графический интерфейс запускается, доступны 9 вкладок.

Для запуска: `python autosalon.py`. Для проверки: `python proverka_raboty.py`. Нужен Python с Tkinter.
