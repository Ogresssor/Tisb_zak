# Этап 1. Сеть автосалонов

Разработана структура информационной системы из 8 таблиц: salons, brands, models, vehicles, customers, employees, sales, payments.

Определены 8 функций системы и 8 запросов, пользователи, требования, сущности и связи, правила целостности и нормализации.

Два вычисляемых столбца:
- vehicles.planned_margin: разница между плановой ценой продажи и закупочной ценой.
- sales.final_amount: сумма продажи с учетом скидки.

Для SQLite подготовлена схема базы. Проверены создание таблиц, расчетные поля и внешние ключи.

Основной сдаваемый файл: «Этап 1. Анализ предметной области и структура БД Сеть автосалонов.docx». В нем представлены две диаграммы и описание всех связей. Оригинал в архиве материалов текущего диалога. Статус сдачи не подтвержден.
