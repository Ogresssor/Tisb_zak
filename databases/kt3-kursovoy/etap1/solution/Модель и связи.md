# Сеть автосалонов. Этап 1

## Предметная область

Система хранит сведения об автосалонах, марках и моделях, автомобилях с уникальным VIN, покупателях, сотрудниках, продажах и платежах. Пользователи: менеджер, администратор салона, руководитель сети.

Основные функции: справочники, поиск машин, регистрация клиентов, оформление продаж, расчет скидки, прием платежей, отчеты по продажам и остаткам.

## Таблицы и ключи

| Таблица | PK | FK |
|---|---|---|
| salons | salon_id | Нет |
| brands | brand_id | Нет |
| models | model_id | brand_id на brands |
| vehicles | vehicle_id | model_id на models, salon_id на salons |
| customers | customer_id | Нет |
| employees | employee_id | salon_id на salons |
| sales | sale_id | vehicle_id на vehicles, customer_id на customers, employee_id на employees |
| payments | payment_id | sale_id на sales |

Связи: brands (1:N) models; models (1:N) vehicles; salons (1:N) vehicles; salons (1:N) employees; vehicles (1:0..1) sales; customers (1:N) sales; employees (1:N) sales; sales (1:N) payments.

UNIQUE: brands.name, models(brand_id,name), vehicles.vin, customers.phone, sales.vehicle_id.

Вычисляемые поля: vehicles.planned_margin = list_price - purchase_price; sales.final_amount = ROUND(base_price * (100 - discount_pct) / 100, 2). Задолженность по оплате рассчитывается запросом по payments.

Схема рассчитана на выполнение 3НФ при принятых функциональных зависимостях. Данные не заполняются до этапа 2. При заполнении необходимо не менее десяти записей в каждой таблице.
